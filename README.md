# Nguyen Cao Nhan — Portfolio

Personal portfolio site built with React, Vite, and Tailwind CSS v4.

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy

Push to a Git repo and import it in [Vercel](https://vercel.com/new) — it auto-detects
Vite (build command `npm run build`, output directory `dist`). No extra config needed.

## Content

Resume/profile content lives in [`src/data/resume.js`](src/data/resume.js) — edit it to
update copy without touching component code.
